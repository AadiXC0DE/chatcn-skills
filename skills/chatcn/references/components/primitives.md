# Primitives

Menu, popover and dialog, styled for chatcn. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## Free

- `menu`: **Menu.** Dropdown menu on Base UI: actions, checkbox and radio items, groups, shortcuts and submenus, with concentric radii and keyboard-aware motion.
- `popover`: **Popover.** Floating panel on Base UI with the kit's surface, origin-aware motion and no animation when opened from the keyboard.
- `dialog`: **Dialog.** A Base UI dialog on the chatcn surface. Traps and returns focus, closes on Esc, and grows from the center in 220 ms.
