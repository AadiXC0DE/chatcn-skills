# Chat layouts

Chat placed in an app: copilot drawer, launcher widget, ask popover, split and threaded chat, spotlight and notch chat, docs ask. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## chatcn Pro

- `copilot-drawer` (Pro): **Copilot drawer.** An in-app copilot beside the page: it shows what it reads as chips, rings each part on the page, lets you leave parts out, and docks or floats.
- `launcher-widget` (Pro): **Launcher widget.** The chat bubble for a website, done properly: unread count, a greeting that steps aside, and a panel that grows out of the launcher.
- `ask-popover` (Pro): **Ask popover.** Ask about any selection in an app: an Ask button at the selection, the answer streaming in a popover right there, and a way to keep it as a thread.
- `mini-chat` (Pro): **Mini chat.** A picture in picture chat over the app: fling it to a corner, move it from the keyboard, or shrink it to a pill that follows the answer.
- `threaded-chat` (Pro): **Threaded chat.** Threads off any message, with the agent answering inside the thread, so side questions stop burying the main conversation.
- `split-threads` (Pro): **Split threads.** Two threads side by side, for comparing models or prompts: one composer for either side or both, linked scrolling, and swap.
- `focus-chat` (Pro): **Focus chat.** A centered, distraction free chat: while you type, the chrome fades and earlier turns step back; a small pointer movement brings them back.
- `agent-timeline-layout` (Pro): **Agent timeline layout.** A long running agent's thread as a timeline, with honest gaps between steps and a composer that steers without stopping the run.
- `canvas-chat` (Pro): **Canvas chat.** A chat on an infinite canvas where prompts and answers are nodes you can branch from, drag, pan and zoom.
- `tree-chat` (Pro): **Tree chat.** The conversation as a branching map beside the thread: click a node to open that path, hover to preview it.
- `spotlight-chat` (Pro): **Spotlight chat.** A command bar that answers: one line that grows into suggested actions as you type, then into an answer panel that follows the reply as it streams.
- `notch-chat` (Pro): **Notch chat.** A compact island at the top center that listens, thinks, opens into a chat while it answers, and shrinks back to a one line summary.
- `terminal-chat` (Pro): **Terminal chat.** Chat in a terminal: a prompt glyph, mono type, slash commands with ghost completion, arrow up history and tool calls as blocks with their output.
- `docs-ask` (Pro): **Docs ask.** The Ask panel for a docs site: answers scoped to the page, numbered citations that jump to the heading they used, questions about a selected passage, and a plain not in these docs state.
