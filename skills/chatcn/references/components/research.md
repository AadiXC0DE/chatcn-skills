# Research

Deep research: progress, reports, search results, source documents, document viewer, canvas, inline suggestions. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## Free

- `research-progress`: **Research progress.** A deep research run from plan to report: four phases, the sources read, elapsed time, the page being read right now, and Cancel.
- `research-report`: **Research report.** A long report built for reading: 68ch measure, a table of contents that follows you, citations that preview and jump to sources, and export.
- `search-results`: **Search results.** Web results from a search tool in three views: a full list, a compact list and an image grid, with the query and result count on top.
- `source-document`: **Source document.** A document source with its cited page. Opens the document with the passage highlighted and scrolled into view.
- `document-viewer`: **Document viewer.** Page sheets with the cited passage highlighted, a rule in the margin and page navigation that follows your scroll.
- `canvas`: **Canvas.** A document canvas for writing with an agent: select to ask, suggested edits that stream in place, accept or reject each one, and version history.
- `selection-toolbar`: **Selection toolbar.** A floating toolbar over selected text with Ask, Rewrite, Explain and Copy. Ask turns it into a question field.
- `inline-suggestion`: **Inline suggestion.** Ghost text completion after the caret in a plain textarea. Tab accepts, Esc dismisses.
