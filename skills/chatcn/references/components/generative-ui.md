# Generative UI

UI the model renders from tool output: the genui renderer, charts, stat cards, forms, tables, carousels and cards for events, products, flights, orders. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## Free

- `chatcn-genui`: **Generative UI renderer.** Renders a JSON spec from the model as chatcn widgets: validated with Zod, drawn while it streams, and safe when the model gets it wrong. Accepts A2UI-style trees too. Docs: https://chatcn.dev/docs/components/gen-ui-renderer.md.
- `chart`: **Chart.** Bar, line, area and proportion charts that stay quiet until pointed at: rounded gapped bars, smooth lines over gradient areas, a floating tooltip card, a headline number with a delta chip, and a segmented donut. Color-blind aware, with a table for screen readers. No chart library. Also called: graph, bar chart, line chart, area chart.
- `stat-card`: **Stat card.** A figure with a delta chip and a sparkline. The chip knows whether up is good, the sparkline fades to its baseline under a haloed end dot or draws as bars, a target shows progress toward a goal, and a group splits stats with hairlines instead of nesting cards. Also called: kpi, kpi card, metric card, stat tile.
- `comparison-table`: **Comparison table.** Options side by side with the best value in each row marked, the recommended option tinted, and a choose button per column. The attribute column stays put while options scroll.
- `form-widget`: **Form widget.** A form the agent asks the user to fill in. Validates on blur and on submit with messages that say how to fix the value, hands values back through a callback, then becomes a read-only summary.
- `calculator-widget`: **Calculator widget.** A small interactive tool inside an answer. Sliders and exact fields drive live results, from formulas the model writes or a compute function you pass.
- `card-carousel`: **Card carousel.** Horizontal results such as places, products or events. Cards snap one by one, arrows page the rail and disable at either end, and images hold their frame while they load.
- `map-placeholder`: **Map placeholder.** A location card with a monochrome street pattern seeded from the coordinates, so the same place always looks the same and nothing waits on a map provider. Drop in a static map or a live one when you have it.
- `weather-card`: **Weather card.** The reference generative widget: current conditions, an hourly strip and a week of ranges on one shared scale, like a thermometer laid flat. Also called: weather widget.
- `timeline-widget`: **Timeline widget.** Events or steps on a vertical rail. In steps, the rail is solid up to the current step and quiet after it, so progress reads without color.
- `confirmation-card`: **Confirmation card.** The safe pattern for actions an agent takes on the user's behalf: everything that will happen in plain rows, one explicit confirm, and a receipt afterwards. Confirm stays blocked while the summary streams or after the quote expires.
- `mcp-app-frame`: **MCP app frame.** Hosts an MCP App (a ui:// resource, text/html;profile=mcp-app) in a sandboxed iframe through the official app bridge: loading, errors, resize to content, chatcn tokens as host styles, full screen, picture in picture, and tool input and output passthrough.
- `event-card`: **Event card.** A calendar event from a tool result: when, in your zone and theirs, where, who is coming, a reply that rolls back if it fails, an amber note when it overlaps something else, and Add to calendar for Google, Outlook or an .ics file.
- `product-card`: **Product card.** A shopping agent's result: photo, price and sale price in the right currency, a rating you read as a shape, color swatches and sizes that are real radio groups, stock, delivery, compare and an Add to cart that shows progress and confirms.
- `flight-card`: **Flight card.** A flight option from a travel agent: carrier, times and airports on a drawn route line with the kit's square marks, stops with their layovers, then price, cabin, bags and one select action. Return trips stack their legs.
- `order-summary`: **Order summary.** The last step of agentic checkout: every line, charge and address in tabular figures, then a purchase that cannot happen by accident. Hold to pay, or press once to arm and once to confirm, with processing, placed and failed states.
- `contact-card`: **Contact card.** A person or a business the agent found. People show their local time and how far it is from yours; businesses show whether they are open right now, worked out from their hours in their own zone. Every value copies.
- `quick-replies`: **Quick replies.** Choices the model offers inline. Single select sends on the first pick, multi select collects picks for one Send, and Other opens a field for anything the options missed. Once answered, the replies lock to a record of the choice.
- `ticker-card`: **Ticker card.** A stock or crypto quote: price, change in green or red with an arrow, a price line you can scrub, ranges, market status, and an amber note when the data is stale. Props only: the card never fetches.
