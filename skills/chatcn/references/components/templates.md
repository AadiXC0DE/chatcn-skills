# Templates

Complete apps: observability, eval platform, knowledge workspace, voice agent console, image, video and TTS studios, AI SaaS starter, AI product site. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## chatcn Pro

- `observability-app` (Pro): **Observability app.** An observability app for agents on scripted fixtures: every trace with its waterfall and span detail, usage with the budget, spend, latency, tokens, routing and uptime, errors grouped with a live log, and alert rules with incidents. Firing alerts and error samples open the traces behind them.
- `eval-platform-app` (Pro): **Eval platform app.** An eval platform for one prompt on scripted fixtures: a playground with versions and a model comparison, datasets, experiments with live progress against a baseline, a review queue and the judge's rubric. Datasets start experiments, failed cases open in the playground and answers marked bad flow back into a dataset.
- `knowledge-workspace-app` (Pro): **Knowledge workspace app.** A knowledge workspace on scripted fixtures: sources with indexing and connected drives, a chat whose answers cite the exact passage, flag claims no source backs and show their grounding and retrieval, a two host audio overview you can cut into, flashcards, a quiz and a briefing, and a mind map and graph of the sources.
- `video-studio-app` (Pro): **Video studio app.** A complete video generation studio on scripted fixtures: the prompt bar with start frame, length, aspect and camera, takes that arrive frame by frame on honest progress, a player and a side by side compare, a storyboard, a multitrack edit, a render queue, credits and an export that records the edit to a file.
- `voice-agent-console` (Pro): **Voice agent console.** A voice agent console on scripted fixtures: agents in the rail, each one's configuration as a draft you publish, a test call that runs the draft against a simulated caller, and a call log whose rows open a full review with the recording, tools and latency per reply.
- `tts-studio-app` (Pro): **TTS studio app.** A complete text to speech studio on scripted fixtures: a long form script with a voice and takes per paragraph, a panel for voice, delivery, take compare and stretch fixes, the voice library with design and clone, characters spent per take, and an export that renders real WAV files.
- `image-studio-app` (Pro): **Image studio app.** A complete image generation studio on scripted fixtures: projects and collections, the imagine bar, runs that arrive through the dither reveal on honest progress, a virtualized history, a viewer with variations and edit history, inpaint mode, credits and a paywall.
- `ai-saas-starter` (Pro): **AI SaaS starter.** A complete AI product on mocks, routed by state in one component: sign in with an email code, onboarding in three steps, the chat app with model picker and tool calls, credits every message spends, billing, and settings for the profile, API keys and usage.
- `ai-product-site` (Pro): **AI product site.** A full marketing site for a fictional AI product, assembled from the Marketing family: a sticky nav, the live chat hero, a customer row, use cases with running demos, the pipeline, an API sample that streams, the usage price calculator, questions and a footer.
