# Marketing

Landing sections for AI products: animated heroes (voice, composer, live chat, terminal agent), use case switcher, pipeline diagram, price calculator. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## chatcn Pro

- `sticky-device-story` (Pro): **Sticky device story.** A sticky device whose screen changes as the steps beside it scroll past.
- `hero-voice` (Pro): **Hero voice.** A hero whose main object is a voice agent you can watch and talk to. A scripted call plays on view with live captions; visitors tap the orb to cut in, replay it, hear it in the browser's voice, or switch to their own microphone and watch the orb follow them.
- `hero-composer` (Pro): **Hero composer.** A landing hero whose main object is the composer itself: example prompts take turns in the placeholder, files attach, the model chip opens a menu and Send routes to your app.
- `hero-live-chat` (Pro): **Hero live chat.** A hero whose main object is a working chat run: a scripted question with tool calls, sources and a streamed answer that visitors can replay, stop or take over by typing.
- `hero-prompt-to-image` (Pro): **Hero prompt to image.** An image model hero: a prompt goes in and the picture arrives through the dither reveal, with a live timer and the run's facts underneath. Chips queue another prompt.
- `hero-terminal-agent` (Pro): **Hero terminal agent.** A coding agent hero: a session plays in a terminal once it scrolls into view. Commands land, the agent works its steps, a diff lands and the tests pass.
- `hero-ascii` (Pro): **Hero ASCII.** A hero with the product screenshot set in ASCII beside the headline. When it scrolls into view it resolves, once, from characters into the real screenshot.
- `hero-dithered` (Pro): **Hero dithered.** An editorial hero: a large dithered plate on one side, tight type and a hairline row of figures on the other, set off center like a magazine opener.
- `use-case-switcher` (Pro): **Use case switcher.** Tabs that swap a live demo per use case (support, coding, research, voice), with autoplay and a progress hairline per tab that holds whenever the visitor is busy.
- `pipeline-diagram` (Pro): **Pipeline diagram.** An agent pipeline (input, tools, model, output) with small square packets running along hairlines while each step lights in turn, the way a request moves through the system.
- `api-snippet` (Pro): **API snippet.** A code sample with language tabs and copy, and a response pane that streams the JSON reply when Run is pressed, with its status, latency and size.
- `usage-price-calculator` (Pro): **Usage price calculator.** Sliders for what a customer will use (tokens, images, voice minutes) and what every plan would cost for it, with the cheapest plan that covers the usage marked.
