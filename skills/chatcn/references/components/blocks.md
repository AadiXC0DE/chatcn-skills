# Blocks

Whole screens in one install: chatbot, coding agent, research agent, agent ops, app builder, plus an AI product hero, pricing and FAQ. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## Free

- `chatbot`: **Chatbot.** A complete chat app surface: streaming Markdown, reasoning, tool calls with approvals, message actions, an empty state and a composer with attachments, model picker and reasoning effort. One install, a few lines to wire to AI SDK. Also called: chat app, ai chat app, chatbot template, chatgpt style app.
- `ai-product-hero`: **AI product hero.** A landing hero for an agent product: an editorial headline row over a live agent run that tracks its own steps and the metric it fixes.
- `ai-pricing`: **AI pricing.** Pricing for an agent product: plan columns with a live usage estimate in each, monthly or yearly billing, overage math and a model comparison.
- `faq`: **FAQ.** Questions and answers, with a last row where anyone can ask their own. An asked question stays in the list as a row of its own, its answer streaming in beneath it.
- `coding-agent`: **Coding agent.** A Claude Code and Cursor style coding agent in one block: the thread with reasoning, tool calls and approvals, a workspace with changed files, diffs and the agent's terminal, todos, a message queue, permission mode and a context meter.
- `research-agent`: **Research agent.** A deep research surface: the conversation with a live progress card, search results streaming in, every source found, read and cited, and the finished report with citations. A composer with deep research mode. Everything is derived from the messages.
- `agent-ops`: **Agent ops.** Mission control for background agents: every run in one inbox, every approval in one queue, the selected run's live trace and an activity feed. Approve from anywhere and the run picks up where it stopped.
- `app-builder`: **App builder.** Describe an app and watch it build: chat on one side, the running app on the other with versions, device sizes, a code view that streams files as they are written, and select and comment tools over the preview.
