# Computer use

Agents driving a browser: agent cursor, set of marks, agent browser frame, action filmstrip, form fill review, sensitive action gate. Install a free item with `npx shadcn@latest add @chatcn/<name>` and a Pro item with `npx shadcn@latest add @chatcn-pro/<name>`. Full docs for any item: `https://chatcn.dev/docs/components/<name>.md`.

## chatcn Pro

- `agent-cursor` (Pro): **Agent cursor.** The agent's pointer over a live or recorded screen, with an action label and click rings.
- `set-of-marks` (Pro): **Set of marks.** Numbered boxes over every interactive element, the way the model sees the page.
- `agent-browser-frame` (Pro): **Agent browser frame.** A small browser the agent drives while you watch, with take over and hand back.
- `action-filmstrip` (Pro): **Action filmstrip.** A frame per step with the action and the reason. Scrub, jump and step through.
- `parallel-tabs` (Pro): **Parallel tabs.** Every tab an agent works in at once, each with its own status and progress.
- `form-fill-review` (Pro): **Form fill review.** Every field the agent filled, with its source and an edit, before submit.
- `sensitive-action-gate` (Pro): **Sensitive action gate.** Confirm before the agent pays, sends, deletes or signs in, with the exact details.
- `sign-in-handoff` (Pro): **Sign in handoff.** The pause where the human signs in and hands control back to the agent.
- `dom-action-log` (Pro): **DOM action log.** A readable log of what the agent clicked and typed, with selectors on demand.
